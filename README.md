# 4D4Y 浏览器插件 (4d4y-browser)

DSH(DeepSeek Harness)插件:在 GUI 内直接浏览 4D4Y 论坛(https://www.4d4y.com/)的专属浏览器。

## 功能

- **浏览**:版块首页、帖子列表、楼层正文,无需离开 DSH
- **图片**:同一楼层多图横向并排、懒加载、点击看原图
- **登录**:面板内直接登录,登录后可浏览更多版块(如生活版区)
- **发帖 / 回复**:支持 bbcode,可一次上传多张图片
- **黑名单屏蔽**:一键开关,自动隐藏黑名单用户的楼层
- **界面**:全屏面板(保留 GUI 侧边栏)、配色跟随主题、16px 大字

## 安装

在任意 DSH 会话中输入:

```
安装 https://github.com/lovaxi/4d4y-browser 插件
```

DSH 的 AI 会自动完成安装并提示重启。重启后侧边栏底部出现「4D4Y」按钮,打开面板点「登录」输入你的 4D4Y 账号即可。

> 支持 Windows / Linux / macOS。

## 使用

- 工具栏:首页 / 后退 / 前进 / 刷新、登录/登出、黑名单开关、关闭
- 版块页「发新主题」,帖子页「回复本主题」,均可「📷 添加图片(可多选)」
